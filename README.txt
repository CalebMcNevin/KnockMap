Door-Knocking Report Map
========================

How to use:
1. Keep these files together in one folder.
2. Double-click "index.html" (opens in your browser).
3. Drop your season report CSV onto the page.

That's it. Nothing is uploaded anywhere -- the report is read
directly in your browser and never leaves your computer.

Tips:
- Pick a metric from the "Color/size by" dropdown; the map recolors.
- Click any zip/FSA for the full row of numbers.
- "Filter ... >=" hides low-significance rows (e.g. KnockCount < 50).
- Scale "auto" = robust default; try "custom" to set your own max.
- "Log: auto" handles skewed metrics automatically.
- The "Fit" button zooms back out to all your data.

Requires an internet connection (map tiles + map engine load from
the web), and any modern browser (Chrome, Edge, Firefox, Safari).

example.csv is a sample report you can try on first.
